# AI Skills

Reusable agent skills for structured engineering work and practical planning.

## Available Skills

| Skill | Purpose | Documentation |
|---|---|---|
| Loop Engineering | Structures technical work around planning, execution, observation, verification, reflection, and reporting. | [Guide](loop-engineering/README.md) · [Skill](loop-engineering/SKILL.md) |
| Trip Planner | Plans trips around budget, travel distances, logistics, and current information. | [Skill](trip-planner/SKILL.md) |

## Getting Started

1. Choose a skill from the table above.
2. Read its documentation and `SKILL.md`.
3. Follow your agent's supported instructions for loading skills.
4. Keep referenced files and folders together.

Loop Engineering includes supporting references and portability guidance. Trip Planner is contained in its `SKILL.md` file.

## Scope

These are instructions for an AI agent, not standalone applications. Results depend on the agent's capabilities, available tools, and access.

Review proposed actions before allowing changes to infrastructure or external services. Skill instructions do not replace your organization's approval and security requirements.
